The Mac window has a new layout: the list of runs at the side, filtered by computer, a header over the open run, and Settings inside the window. A run is named by its first message. The Changes panel shows the run’s branch and commits it, then opens a pull request on GitHub, with the run’s shell at its foot. Files drop anywhere on a conversation, a run at its usage limit shows when the limit resets, and a run whose computer can’t be reached says so and keeps what it last read.
